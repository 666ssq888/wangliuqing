GALLERY 01 · FONT ICONS

字体图标馆：
图标即字形。

Font Awesome 以 @font-face 加载字库，每个图标都是一枚字符：用 fa-solid 指定字族，再用 fa-xxx 指定码位， 浏览器便像渲染文字一样渲染图形。因此它继承了文字的一切天赋——任意缩放不模糊、color 直接染色、font-size 即尺寸。 点击下方任意图标，可复制它的类名。

USAGE · 用法

<link rel="stylesheet"
      href="./cdn/fontawesome/css/all.min.css">

<i class="fa-solid fa-palette"></i>
<i class="fa-solid fa-pen-nib fa-beat"></i>

/* 本质是一段字体编码 */
.fa-palette::before {
    content: "\f5fc";   /* 码位 */
    font-family: "Font Awesome 6 Free";
    font-weight: 900;
}
