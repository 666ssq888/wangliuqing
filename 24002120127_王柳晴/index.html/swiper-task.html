💡 问题解答：prev / next 的 transform 各控制什么？

prev 控制"上一张"的退场形态：translate: ["-118%", 0, -320] 让它向左移出画面并沿 Z 轴后退 320px（视觉上缩小远离），rotate: [0, 0, -10] 绕 Z 轴逆时针倾斜 10°，再配合 shadow: true 与 opacity: 0.6，形成"缩小左移带角度"的退场。

next 控制"下一张"的待进场形态：translate: ["118%", 0, 0] 让它预先停在右侧画面外，scale: 1.18 表示初始比正常大 18%，配合 opacity: 0，随着切换进行逐渐放大着从右往左进场并淡入——正是电影选片墙"前一张退到左后、新一张迎面放大而来"的感觉。

一句话总结：prev 管"离开时变成什么样"，next 管"进场前是什么样"，Swiper 在这两个状态之间做补间动画。

往返 1 · creativeEffect 的 transform 怎么写？

官方示例 257-effect-creative.html 里 creativeEffect 的 prev / next 中 translate、rotate 这些数组是什么含义？我要"上一张缩小左移带角度、下一张放大右移进场"。
prev / next 各是一个变换描述对象：translate: [x, y, z] 是三维位移（x 支持百分比字符串，如 "118%" 表示自身宽度；z 轴负值表示远离视口即缩小），rotate: [x, y, z] 是绕三轴旋转的角度（度），另有 scale（缩放）、opacity（透明度）、origin（变换中心）、shadow（投影）。要你的效果：prev 写 translate:["-118%",0,-320], rotate:[0,0,-10], opacity:0.6；next 写 translate:["118%",0,0], scale:1.18, opacity:0。Swiper 会在两个状态间自动补间。

往返 2 · 点按钮换 effect 为什么不生效？

我直接改实例的 effect 参数再 update()，轮播没有变化？
effect 只在初始化时读取，运行期修改无效。必须 destroy(true, true) 销毁旧实例后用新配置重建，建议把公共配置封装成工厂函数（本页的 wlq_createSw4(wlq_fx)），切换时只改变 effect 参数传入重建。

往返 3 · keyboard 键盘控制怎么开？

课堂上没讲过 keyboard，帮我加上方向键翻页。
配置 keyboard: { enabled: true } 即可，页面聚焦后按 ← / → 前后翻页；可加 onlyInViewport: true 限定仅当轮播在可视区域内才响应，避免长页面误触发。

往返 4 · loop 模式下新增 slide 要注意什么？

第六件展品直接加在 swiper-wrapper 里就可以吗？
可以。直接添加完整的 swiper-slide 结构（img + 图注）即可，Swiper 初始化时会在首尾复制幻灯片实现无缝循环；注意新 slide 要写在 new Swiper() 执行之前，并确认图片路径有效。
