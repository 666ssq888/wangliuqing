图标即字体

Font Awesome 把图标铸成字形，@font-face 加载字库，一个 class 名即可点亮一枚图形，缩放如文字般顺滑。

图标即矢量

Lucide 以 SVG 描边作画，线条粗细、颜色、尺寸皆可随 CSS 自由调度，是像素级掌控者的画笔。
