矢量图标馆：
图标即线条。

Lucide 走的是另一条路：每个图标是一段 <svg> 矢量路径，用 stroke 描边作画。 页面加载后执行 lucide.createIcons()，<i data-lucide="xxx"> 占位符就被替换为真正的内联 SVG—— 于是线宽、颜色、尺寸全部交由 CSS 摆布。拖动下方滑杆，亲手指挥一支画笔。

USAGE · 用法

<script src="./cdn/lucide/lucide.min.js">
</script>

<i data-lucide="palette"></i>

<script>
  // v1.x 需显式传入图标库
  lucide.createIcons({ icons: lucide.icons });
</script>

/* 渲染结果（可被 CSS 完全控制） */
<svg stroke="currentColor"
     stroke-width="2" fill="none">
  <path d="M12 22a10 10 0 1 1 10-10..."/>
</svg>

两种哲学 FONT vs SVG

字体图标（iconfont-1）

  • 一次 @font-face，全站字形统一加载
  • 写法轻便：一个 class 名即一枚图标
  • 受字体渲染管线约束，多色支持有限
  • 样式只能调 color / font-size / 阴影

SVG 矢量图标（本页）

  • 真矢量路径，任意缩放永远锐利
  • stroke-width、fill、渐变皆可编程
  • 支持多色、描边动画、CSS 变量驱动
  • 内联即 DOM，可被 JS 逐节点操控
